# Oficina visual — proporções e cenário

Protótipo DEV sobre cópias locais das fases de controle, sem ranking oficial. SVG 64×64, grade ortogonal, vista superior estilizada com profundidade frontal curta. Piso discreto, obstáculos contrastantes, silhuetas distintas; portas abertas revelam o chão sem números. Testar leitura em 5×5, 8×8 e 12×12, celular e desktop. Arte vetorial inicial, não estudo externo formal. Não alterar colisões para acomodar arte.
